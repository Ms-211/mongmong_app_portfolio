# 몽몽플레이 · 공개 포트폴리오 데모

보드게임 카페 고객이 게임을 찾고, 함께할 인원과 취향에 맞는 게임을 추천받으며, 메뉴와 매장 이용 정보를 확인할 수 있는 Flutter 애플리케이션입니다.

## 실제 운영 사이트

[몽몽플레이 운영 사이트 바로가기](https://mongmongplay.pages.dev/)

실제 고객에게 공개해 운영 중인 사이트입니다. 이 저장소는 공개용 데모 사본이므로 운영 사이트의 이미지·폰트·매장 정보와 차이가 있습니다.

> **공개 데모입니다.** 운영 Wi-Fi·SNS 계정·QR, 실제 게임 위치·설명·등록일·메뉴 가격을 데모 값으로 교체했습니다. 기존 이미지·폰트는 포함하지 않고 직접 생성한 PNG와 기본 폰트를 사용합니다. 안내 화면의 요금·이벤트 문구는 동작 설명용 예시이며 실제 운영 정보를 보장하지 않습니다. 게임 이름·플레이 정보와 YouTube ID는 유지했습니다. 과거 커밋과 운영 배포 설정은 포함하지 않습니다.

[공개 범위와 검증 기록](docs/public-release.md)

## 프로젝트 개요

게임 선택에 필요한 인원·난이도·장르·시간 정보를 한곳에 모으고, 상세 화면에서 매장 내 위치와 설명 영상을 확인할 수 있도록 구성했습니다. 가로형 대화면에서 사용할 수 있는 매장 안내 UI를 중심으로 구현되어 있습니다.

게임과 메뉴는 앱에 포함된 JSON에서 읽습니다. 별도 백엔드 없이 검색과 추천을 수행하며, 설명 영상은 YouTube 플레이어를 사용합니다.

## 주요 기능

| 기능 | 구현 내용 |
| --- | --- |
| 보드게임 검색 | 이름 검색, 인원·난이도·장르·시간 필터, 최근 등록 게임 조회 |
| 조건별 추천 | 인원 선택 후 분위기·난이도·시간을 선택하여 가중치 기반 추천 결과 조회 |
| 게임 상세 | 이미지, 설명, 플레이 정보, 매장 내 위치, YouTube 설명 영상 |
| 메뉴 안내 | 카테고리별 메뉴와 가격 표시, 카테고리 이동 및 스크롤 위치 연동 |
| 매장 안내 | 이용 요금·이용 방법·정리 안내·공지·이벤트 |
| SNS·Wi-Fi 안내 | Wi-Fi 정보와 SNS·지도 QR 이미지 표시 |

문서 작성 시점의 데이터는 게임 **409개**, 메뉴 **45개**입니다. 게임 목록에서는 활성 상태인 항목만 표시하므로 실제 노출 수는 데이터 전체 개수와 다를 수 있습니다.

## 구현에서 살펴볼 부분

- **조건을 모두 만족하지 않아도 추천:** 플레이 가능한 인원을 먼저 확인하고, PICK 여부·추천 인원·장르·난이도·시간 점수를 합산해 결과를 정렬합니다.
- **데이터와 화면의 역할 구분:** JSON 로딩은 Repository, 데이터 변환은 Model, 표시와 사용자 입력은 Screen에서 처리합니다. 검색과 추천 계산은 현재 검색 화면에 들어 있습니다.
- **화면 간 흐름 재사용:** 추천 질문 화면이 선택 조건을 검색 화면에 전달하고, 검색 화면의 추천 모드에서 결과를 보여줍니다.
- **웹 실행:** Flutter Web으로 실행합니다. 운영본의 자동 배포 설정은 제외했습니다.

추천은 규칙과 점수를 이용하는 방식이며, 학습 모델이나 사용자 행동 기반 개인화는 사용하지 않습니다.

## 로컬 실행

운영본과 맞추려면 Flutter **3.44.2**를 사용합니다. pubspec.yaml의 Dart SDK 조건은 **^3.12.1**입니다. 공개본은 Web 실행을 대상으로 합니다.

```sh
git clone https://github.com/Ms-211/mongmong_app_portfolio.git
cd mongmong_app_portfolio
flutter pub get
flutter run -d chrome
```

운영 저장소와 분리된 공개용 사본이며 운영 Git 이력은 포함하지 않습니다.

```sh
flutter analyze
flutter test
flutter build web --release
```

현재 테스트는 1920×1080 크기에서 홈 화면의 '보드게임 찾기' 문구를 확인하는 위젯 테스트입니다. 검색·추천·영상 재생·모바일 레이아웃까지 검증한 테스트는 포함되어 있지 않습니다.

## 현재 범위와 개선 과제

- 게임·메뉴는 정적 데이터이므로 수정 후 재빌드·배포가 필요합니다. 주문·결제·관리자 CRUD는 구현 범위에 포함되지 않습니다.
- UI는 화면 너비와 높이 비율로 구성됩니다. 세로형 스마트폰을 포함한 모든 해상도의 대응을 보장하지 않습니다.
- JSON 로딩 실패에 대한 오류 안내와 재시도, 추천 계산의 분리 및 테스트는 개선 과제입니다.
- 사용자 수, 업무 개선 수치, 개발 기간 및 개인 기여 범위는 이 저장소만으로 확인할 수 없어 기재하지 않았습니다.
