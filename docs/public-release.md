# 공개 범위와 검증 기록

## 운영본과 분리

현재 파일만 새로 복사했습니다. 운영 Git 이력·원격 설정·자동 배포 워크플로·다른 플랫폼 프로젝트는 가져오지 않았습니다. 운영 저장소 코드는 변경하지 않았습니다.

## 교체 내역

- Wi-Fi: DEMO_WIFI / DEMO_ONLY
- SNS 계정: @demo_account
- Wi-Fi·SNS·지도 QR: 스캔 코드가 없는 DEMO 이미지
- 게임·메뉴 이미지, 로고·삽화·웹 아이콘: 직접 생성한 PNG
- 폰트: 기존 파일과 등록 제외, 시스템 기본 폰트 사용
- 게임 구역·위치·설명·등록일, 메뉴 가격: 데모 값
- Cloudflare 배포 워크플로: 제외

게임 이름·플레이 정보·YouTube ID는 검색과 추천 시연을 위해 유지했습니다. 영상 파일은 복사하지 않습니다. 기존 이미지와 폰트는 권리 정보를 확정하지 못해 제외했습니다. 안내 화면의 요금·이벤트는 예시 표시이며 실제 운영 정보를 보장하지 않습니다.

## 검증과 한계

운영 Wi-Fi 값과 SNS 계정이 공개 파일에 없는지, 고위험 토큰 패턴·비밀키 파일·배포 설정 포함 여부를 정적으로 점검했습니다. 데이터 개수, 이미지 경로, PNG 파일 구조, 폰트 제거와 문서 링크를 확인했습니다.

Flutter 런타임 도구가 없어 분석·위젯 테스트·웹 빌드 및 실제 화면 실행은 하지 못했습니다. 정적 점검은 모든 취약점이 없다는 보장이 아닙니다. 운영 비밀번호의 과거 유출 여부는 공개 사본 제작으로 해결되지 않습니다.
