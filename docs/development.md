# 공개본 실행과 검증

운영 커밋 이력, GitHub Actions, Cloudflare 연결과 다른 플랫폼 프로젝트는 제외했습니다. 이 공개본의 대상은 Flutter Web입니다.

## 실행

운영본과 맞추려면 Flutter 3.44.2 stable을 사용합니다. Dart SDK 조건은 ^3.12.1입니다.

~~~sh
flutter --version
flutter doctor
flutter pub get
flutter run -d chrome
~~~

## 검증

~~~sh
flutter analyze
flutter test
flutter build web --release
~~~

현재 위젯 테스트는 1920×1080에서 홈 화면 문구를 확인합니다. 전체 기능 검증은 아닙니다. 검색·필터·추천·상세 영상·메뉴 스크롤과 실제 기기 화면을 추가로 확인하세요. 영상 재생은 인터넷 연결이 필요합니다. 공개본 QR과 Wi-Fi는 실제 접속용이 아닙니다.

공개본에는 자동 배포가 없습니다. 게임 이미지와 브랜드 삽화는 원본 디자인을 재현하지 않는 직접 생성한 대체 이미지입니다.

## 포트폴리오 소개

409개 게임 데이터를 활용한 보드게임 카페용 Flutter 검색·추천 및 매장 안내 서비스의 공개 데모입니다. 인원·장르·난이도·시간을 이용한 가중치 추천, 게임 상세 및 외부 설명 영상, 메뉴 카테고리 탐색을 구현했습니다.

개인 담당 범위·개발 기간·운영 실적은 확인 가능한 자료와 함께 별도로 기재하세요.
